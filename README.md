# 三重仁義街 開放世界（五華國小）

單一檔案 `index.html`（Three.js r128，從 CDN 載入），直接用瀏覽器開，或開 GitHub Pages 就能玩。

## 給 AI（ChatGPT／Claude）修改時的說明
- 全部程式都在 `index.html` 一個檔案裡（約 42 萬字元）。檔案很大，請只貼要改的那一段給 AI，並用「搜尋這段文字、換成這段」的方式改，不要整份重寫。
- 座標：x 往東、z 往北為負，單位公尺。
  - 五華國小 x[-52,55] z[-412,-186]；仁義門 z -186；一心樓 z[-213,-197]（BZ1=-213, BZ2=-197）
  - 南中庭 x[-26.6,22.6] z[-254.6,-215.4]；大溜滑梯中心 (0,-246.5)
  - 三民樓 z[-269,-257]，中廊 x[-5,5]：縮小版重陽橋＋兩側書櫃
  - 北中庭 x[-26.6,22.6] z[-304.6,-271.4]；頒獎台 (-2,-281.2)
  - 六藝樓 z[-331,-307]；圓形穿堂中心 (0,-331) 半徑 8.4；左右雙側樓梯由一樓 1.35m 走到二樓 4.8m
  - 五育樓 x[-45,-29]；教學農園 x[-52,-31.6] z[-256.8,-213.2]
  - 操場中心 (-18,-371) 外圈 rx21/rz32；直道 x[-41.5,-37.7] z[-405,-348]
  - 綜合球場 x[7.5,34.5] z<-339；停車場 x[38.6,54.6] z[-398,-344]；後門 x≈41.5 z -412
- 學習區墊高：`LIFT=1.2`。`FOOT` 矩形（大樓＋走廊）裡的靜態物件和 `walkRects` 會在 `liftSchool()` 自動抬高 1.2；人物每幀由 `liftApply` 抬高。在大樓範圍裡新增東西時用地面高度 0.15 來寫，程式會自動抬。
- 校園基座樓梯在 `STAIRS` 清單；圓形穿堂新增的左右雙樓梯在穿堂建構區獨立生成，含 `walkRects` 可走踏階。二樓中央走道 x[-3.25,3.25] z[-323.06,-307.5]。玩家地面判定使用當前高度避免穿樓層。
- 常用函式：
  - `boxR(x1,x2,z1,z2,y0,h,mat,{col:1})` 方塊（col:1 會擋人）
  - `flat(cx,cz,w,d,mat,y)` 地面貼圖
  - `vplane(x,y,z,w,h,mat,ry)` 直立平面（招牌）
  - `cyl(x,y,z,rTop,rBot,h,mat,seg)`、`tex(w,h,drawFn)`、`signMat(文字,底色,字色)`
  - `addCol(x1,z1,x2,z2)` 碰撞；`addInteract(x,z,半徑,'按鈕文字',fn)` 互動
  - `walkRects.unshift([x1,z1,x2,z2,高度])` 可以走上去的高台
  - `tallTree(x,z,高,'broad|slender|pine|palm|shrub')` 樹；`slideChannel(點陣列,寬,顏色,扶手色)` 滑梯；`makeChibi({...})` Q 版人物
  - 會動的人寫在 `updateExtras(dt,time,camP)`
- 改完一定要用瀏覽器打開，看 Console 有沒有紅字錯誤。
